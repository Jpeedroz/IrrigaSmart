# IrrigaSmart

Sistema de irrigação inteligente desenvolvido com ESP32, sensores, backend, banco de dados PostgreSQL e dashboard.

## Estrutura do projeto

- `backend/` — API e comunicação com o banco de dados.
- `frontend/` — Interface web e dashboard do sistema.
- `esp32/` — Código do ESP32 e comunicação com os sensores.
- `database/` — Scripts do banco de dados PostgreSQL.
- `docs/` — Fluxos, diagramas e documentação do projeto.
